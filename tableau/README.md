# Tableau Dashboards

The dashboards for this project were built in Tableau Desktop using Databricks-backed tables, then published individually to Tableau Public using an extract-based version for public sharing.

## Tableau Public
https://public.tableau.com/app/profile/bhavik.patwa/vizzes

## Published Dashboards
- Executive Portfolio Overview
- Risk Drivers Dashboard
- Vintage and Prepayment Dashboard
- Distress Transition Watchlist Dashboard

## Notes
- The original live workbook was connected to Databricks tables from the 'mortgage_risk.analytics' schema.
- A separate extract version was created to allow publication through Tableau Public.
- Tableau Public was used for portfolio sharing only.
